# Pocket Oddities — 20 playable mobile games

This directory contains a playable, self-contained browser arcade with **20 mini-games**, responsive touch controls, locally saved scores, optional audio and offline caching. These are prototype MVPs, not yet store-ready native apps.

## Run locally

Open `index.html` in a browser or serve the directory using `python3 -m http.server 4173`. For offline install support, host on HTTPS.

## Publish through GitHub Pages

Open this repository's **Settings → Pages**, select **Deploy from a branch**, select the `pocket-oddities-20-games` branch and the `/docs` folder, and save. If Pages is already used by the original Glitch project, switching the source may replace that project's Pages site. In that case, create a separate repository for Pocket Oddities and copy these `docs` files to its root instead.
